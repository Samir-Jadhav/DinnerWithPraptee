# Audio assets

Place the following optional MP3 files in this folder to enable the invitation's sound design:

- `click.mp3`
- `envelope-open.mp3`
- `wax-crack.mp3`
- `whoosh.mp3`
- `success-chime.mp3`
- `piano.mp3`

The site preloads these files and plays them only after a user interaction. Missing files fail silently, so the invitation remains fully usable without audio.
